HOW TO RUN ON XAMPP:
====================

STEP 1: Start XAMPP
  - Open XAMPP Control Panel
  - Start "Apache" and "MySQL"

STEP 2: Copy Files
  - Copy the entire "nikahconnect" folder to:
    C:\xampp\htdocs\nikahconnect\

STEP 3: Setup Database (AUTOMATIC)
  - Open browser: http://localhost/nikahconnect/setup.php
  - This creates the database and sample data automatically
  - After setup, DELETE setup.php (for security)

  --- OR MANUAL SETUP ---
  - Open: http://localhost/phpmyadmin
  - Create database named: nikahconnect
  - Import the file: database.sql

  --- UPGRADING AN EXISTING DATABASE ---
  - If you already imported an OLDER database.sql, do NOT re-import.
  - Instead import: migration_parents.sql  (adds parent/guardian
    accounts, parent-based rishta approval, and visit scheduling).

STEP 4: Open the Website
  - Homepage:     http://localhost/nikahconnect/
  - Admin Panel:  http://localhost/nikahconnect/admin/
